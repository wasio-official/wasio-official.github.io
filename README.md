# 物理竞赛题库 · 展示站

高中物理竞赛试卷与题目的在线题库，配套 GitHub Pages 静态站点。

**线上地址**：<https://wasio-official.github.io/>

---

## 站点结构

**首页与题库功能分离**：首页只作落地页（简介 + 统计 + 入口），
搜索与试卷浏览集中在独立的题库页。

| 页面 | 地址 | 内容 |
|------|------|------|
| 首页（落地页） | `/index.html` | 标题、简介、总览统计、两个入口按钮 |
| 题库 | `/library.html` | 试卷目录、搜索 / 类型 / 排序筛选 |
| 考点导航 | `/tags.html` | **四级考点级联筛选**，跨试卷汇总该考点下的全部题目 |
| 试卷页 | `/paper.html?id=<试卷slug>` | 该卷题目列表（**仅题号 + 难度 + 考点标签**） |
| 单题页 | `/question.html?p=<试卷slug>&q=<题号>` | 题干、详细解析、答案、11 维度难度评分 |

交互要点：

- **试卷页题目列表只显示标签**，不显示题干摘要，便于快速扫读考点。
- **考点导航页支持四级逐级筛选**：一级 → 二级 → 三级 → 四级，
  选到哪一级就按哪一级汇总（如只选「力学」= 该大类全部 944 题；
  选到「力学/刚体转动/转动定律/转动惯量」= 精确到 9 题）。
  四个下拉逐级联动，面包屑可点击回溯，选择会同步到 URL 便于分享。
- 题库页与试卷页都支持搜索：题库页按试卷名 / 考点标签，试卷页按题号 / 考点标签。
- **解析与答案默认折叠**，点击标题展开；右上角「显示全部」一键展开/收起。
- 公式用 **MathJax** 渲染，图片懒加载。
- 单题页支持键盘 `←` `→` 切换上一题 / 下一题。
- 响应式布局，手机 / iPad 可用。

## 站点图标

图标源文件是 `wasio.jpg`（`WASIO` 词标）。**它不能直接当 favicon**：
词标是 554×283 的 2:1 宽文字，缩进 16px 方形图标后每个字母只剩约 3px，
必然糊成一团（实测确实无法辨认）。

采用的方案是**「小尺寸用首字母 W，大尺寸保留全称」**（按尺寸分流）：

| 场景 | 用什么 | 原因 |
|------|--------|------|
| `favicon.ico`（16/32/48/64） | 蓝底 + 白色 **W** | 标签页就这么大，单字母才看得清 |
| `icon-192` / `icon-512` / `apple-touch-icon` | 蓝底 + 完整 **WASIO** | 书签、主屏、分享卡片尺寸够，露全称 |
| 顶栏标识（`brand-word.png`） | 完整 **WASIO** 词标（深色版） | 横向摆放，配标题「Wasio的物理竞赛题库」 |

其中 W **不是字体替代**，而是从原图里抠出的真实字形，且必须用**连通域**抠：

> 整幅词标恰好 5 个连通域（每个字母一个），W 的包围盒是 `x=1..182`（宽 181px）。
> **早期版本按固定列坐标 `x=112` 硬切，切点落在 W 身上，导致右衬线被切掉**，
> 表现为「图标只露出一部分 W」。改用连通域标记后一次就能完整取出。
> 教训：遇到「分离粘连字形」的问题，先做一次连通域分析，别靠调参数猜。

生成脚本见仓库外的 `build_split_icons.py`，改动源图后重跑即可。

## 访问量统计

页脚显示**本站总访客数**，用的 [Vercount](https://github.com/EvanNotFound/vercount)
（不蒜子的替代方案，公益服务，无需注册）。

| 指标 | 含义 | 刷新会不会涨 |
|------|------|-------------|
| `site_uv` 独立访客数 | 首次访问该浏览器计 1 个访客 | **不会**（页面显示的就是这个） |
| `site_pv` 总访问量 | 每访问一次 +1 | 会 |

前端逻辑在 `assets/visits.js`，直接调接口：

```
POST https://events.vercount.one/api/v2/log
body: { "url": "<当前页地址>", "isNewUv": true|false }
resp: { "status": "success", "data": { "site_uv": N, "site_pv": N, "page_pv": N } }
```

- **去重方式**：写入一年期的 cookie `wasio_seen`，存在即视为非首次访问，
  因此同一浏览器只贡献 1 个访客 —— **刷新、换页都不会让数字增加**。
- **统计与你电脑是否开机无关**：请求由访客的浏览器直接发往 Vercount 服务器，
  本机只是用来构建/推送站点。
- **失败降级**：接口超时（6s）或被拦截时，该行 `hidden`，
  不会显示空白或 0，页脚其余内容不受影响。
- 换浏览器 / 清 cookie / 无痕模式会各算一个新访客，这是这类方案的固有口径。

查看每日趋势、或想改计数起点：登录 [vercount.one](https://vercount.one)
验证域名 `wasio-official.github.io` 后在后台操作。

## 一键发布（日常更新用这个）

题库更新后，**双击 `发布题库.bat`** 即可。它会自动完成：

```
检查环境 → 全量构建 → 校验产物 → 提交推送 → 等 Pages 部署 → 线上抽查
```

完整流程也可以用命令行：

```bash
python publish.py            # 完整发布（会问一次 y/N 确认）
python publish.py --dry-run  # 只构建+校验，不提交（先看看有没有问题）
python publish.py --yes      # 不询问，直接发布
python publish.py --no-verify  # 跳过线上抽查（快一点）
```

**日常加题的步骤**：

1. 把新试卷文件夹放进 `D:\Wasio\Workspace\output`（每个试卷一个目录，内含 `*_第NN题.md`）
2. 双击 `发布题库.bat`
3. 看到「发布完成 ✓」就好了

想先检查不发布，就双击 `检查题库改动.bat`（等于 `--dry-run`）。

### 校验做了哪些事

任一项不通过都会**中止并且不提交**，站点保持原样：

- JSON 产物可解析（`papers.json` / `tags.json` / 每套试卷）
- **逐卷比对题数**：构建出的题数必须等于源目录里的 `*_第NN题.md` 个数
- **图片引用全部存在**：正文里出现的每个 `data/images/...` 都必须在仓库里找得到
- 试卷总数、题目总数不低于下限
- 推送后轮询线上，确认 `papers.json` 的套数与本地一致

### 关于试卷重命名（重要）

`data/papers/<slug>.json` 的文件名是 `slugify(试卷名)` 的哈希，
`data/images/<slug>/` 同理。所以**只要重命名 `output` 里的试卷文件夹，
所有 slug 都会变**，git 会显示成「几千个文件删除 + 几千个新增」。

这是正常的，不是数据损坏 —— `publish.py` 会按**试卷名**比对，
明确告诉你「新增 X 套 / 移除 Y 套」，而不是丢给你一堆文件名。

> 副作用：重命名后旧链接（`paper.html?id=<旧slug>`）会失效。
> 已经分享出去的链接需要重新获取。

## 构建

```bash
# 全量构建（220 套 / 约 2089 题）
python build.py

# 只构建指定试卷（小样抽查 / 增量）
python build.py --papers "2025爱培优一,第42届全国中学生物理竞赛复赛理论试题"

# 只构建前 N 套
python build.py --limit 3
```

`build.py` 会清空并重建 `data/papers/` 与 `data/images/`，然后写入 `data/papers.json`。
构建产物直接位于仓库内，**建议连同 `data/` 一起提交**（GitHub Pages 只托管提交的文件）。

> ⚠️ 因为会清空重建，**不要单独提交某一次 `--papers` 的部分构建结果** ——
> 那会把其余试卷从站点上抹掉。日常发布请用上面的 `publish.py`（始终全量）。

## 标签展示控制（预留）

站点有**两套彼此独立**的标签，都在数据里留好了位置，当前内容为空、不影响显示。

### 一、题目标签（已在用）

题目自带 `tags`（如 `力学/刚体转动/转动定律/转动惯量`），展示规则集中在
`assets/app.js` 顶部的 `TAGS_CONFIG`：

```js
const TAGS_CONFIG = {
  mode: "leaf",        // "leaf" 末级 | "full" 完整路径 | "field" 用新字段
  field: "tag_display",// mode === "field" 时取哪个字段
  max: 0,              // 展示上限，0 = 不限
  tooltip: "full",     // 悬浮提示用完整路径
};
```

改 `mode` 一行即可全站切换（试卷页题目列表、单题页一起生效）。
当前 `leaf` 模式显示路径末级，如 `力学/刚体转动/转动定律/转动惯量` → `转动惯量`。

### 二、试卷标签（预留，当前为空）

`data/papers.json` 里每套试卷都带一个 `tags` 字段，**当前一律为空数组**，
因此题库页卡片上**不显示任何标签，也不会渲染空的标签行**。

- 渲染控制：`assets/app.js` 的 `PAPER_TAGS_CONFIG`（`max` 显示上限、`search` 是否参与检索）。
- 数据来源：`build.py` 的 `_paper_tags()`。它优先读取试卷目录下的
  `paper.yaml` / `_paper.yaml`（写 `tags:` 列表即可）；没有该文件就返回空。
- 列表卡片、搜索都会自动适配 —— 数据一旦有值，标签自动出现，**无需改页面脚本**。

> 说明：历史上卡片标签是从题目标签聚合出来的（`_top_tags`），已按要求改为留空。
> 如需恢复旧行为，把 `_paper_tags()` 末尾 `return []` 换成其上方注释的
> `return _top_tags(questions, 8)` 即可。
> 注意这会让「搜索命中数变多」（试卷标签也参与检索），属预期差异。

### 标签同时支持两种形态

**字符串**与**对象**都可以，对象形如
`{ path: "力学/…/转动惯量", tag_display: "转动惯量" }`，前端两种都能渲染。
